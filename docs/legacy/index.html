# kodplatform

Ekip içi kod + tasarım paylaşım platformu (Gitea benzeri, kendi sunucunuzda barındırılır).

## Özellikler

- **Git entegrasyonu**: Yazılımcılar `git clone / push / pull` ile normal bir Git deposu gibi çalışır (smart HTTP protokolü, `git-http-backend` üzerinden).
- **Tasarım dosyaları**: Tasarımcılar 3D modeller (.fbx, .obj, .stl, .blend, .glb...), çizimler (.psd, .ai, .sketch, .fig, .svg...) ve görselleri REST API ile yükler/indirir. Bu dosyalar Git deposundan ayrı, proje başına klasörlerde tutulur (büyük binary dosyaları Git'i şişirmez).
- **Proje yönetimi sadece admin'e özel**: Proje açma, silme, açıklama/alan/üye değiştirme sadece admin rolündeki kullanıcı tarafından yapılabilir.
- **Roller**: `admin`, `developer`, `designer`. Her projenin kendi üye listesi vardır; admin her projeye erişebilir, diğerleri yalnızca üyesi oldukları projelere.
- **Bağımsız**: Sadece Go standart kütüphanesi kullanılır (harici paket yok), veriler JSON dosyalarında tutulur. Tek dış bağımlılık, sunucuda kurulu olan `git` komutu.

## Kurulum ve Çalıştırma

```bash
go build -o kodplatform ./cmd/server

KP_ADMIN_USER=admin KP_ADMIN_PASS=guclu-bir-sifre \
KP_DATA_DIR=/var/lib/kodplatform \
KP_LISTEN_ADDR=:8080 \
./kodplatform
```

İlk çalıştırmada hiç admin yoksa `KP_ADMIN_USER`/`KP_ADMIN_PASS` ile otomatik admin oluşturulur.

### Ortam değişkenleri

| Değişken        | Açıklama                                      | Varsayılan       |
|-----------------|------------------------------------------------|------------------|
| `KP_DATA_DIR`   | Kullanıcı/proje meta verisi                    | `./data`         |
| `KP_REPOS_DIR`  | Bare git depoları                              | `<DATA_DIR>/repos` |
| `KP_DESIGN_DIR` | Tasarım dosyaları                              | `<DATA_DIR>/design` |
| `KP_LISTEN_ADDR`| Dinlenecek adres                               | `:8080`          |
| `KP_ADMIN_USER` | İlk admin kullanıcı adı                        | `admin`          |
| `KP_ADMIN_PASS` | İlk admin şifresi (zorunlu, admin yoksa)       | -                |

Production'da bunun önüne bir **reverse proxy (nginx/caddy) + HTTPS** koymanız şiddetle önerilir; Basic Auth şifreleri düz metin (TLS altında) gönderilir.

## API Kullanımı

### 1. Giriş yap

```bash
curl -X POST http://localhost:8080/api/login \
  -d '{"username":"admin","password":"guclu-bir-sifre"}'
# -> {"token": "...", "username": "admin", "role": "admin"}
```

Sonraki tüm isteklerde `Authorization: Bearer <token>` header'ı gönderilir.

### 2. (Admin) Kullanıcı oluştur

```bash
curl -X POST http://localhost:8080/api/admin/users \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"username":"ahmet","password":"en-az-6-karakter","role":"developer"}'
# role: "developer" | "designer" | "admin"
```

### 3. (Admin) Proje oluştur

```bash
curl -X POST http://localhost:8080/api/admin/projects \
  -H "Authorization: Bearer $TOKEN" \
  -d '{
    "id": "mobil-oyun",
    "name": "Mobil Oyun",
    "description": "3D mobil oyun projesi",
    "field": "oyun-gelistirme",
    "members": ["ahmet", "ayse"]
  }'
```

`id` aynı zamanda git deposunun adıdır (küçük harf, rakam, `-`). Proje oluşturulunca otomatik olarak:
- boş bir bare git deposu (`<repos>/mobil-oyun.git`)
- boş bir tasarım klasörü (`<design>/mobil-oyun/`)
oluşturulur.

Admin ayrıca `DELETE /api/admin/projects/{id}` ile projeyi (deposu + tasarım dosyalarıyla birlikte) siler, `PATCH /api/admin/projects/{id}` ile bilgi/üye günceller.

### 4. Kod: git clone / push / pull

```bash
git clone http://ahmet:en-az-6-karakter@localhost:8080/git/mobil-oyun.git
cd mobil-oyun
# ... değişiklik yap ...
git add . && git commit -m "özellik ekle"
git push
```

Git istemcisi kimliğini **Basic Auth** ile gönderir (kullanıcı adı + platform şifresi). Sunucu, kullanıcının bu projenin üyesi (veya admin) olduğunu kontrol eder.

### 5. Tasarım: 3D model / çizim yükleme

```bash
# Yükle
curl -X POST http://localhost:8080/api/projects/mobil-oyun/design \
  -H "Authorization: Bearer $TOKEN" \
  -F "file=@karakter.fbx"

# Listele
curl http://localhost:8080/api/projects/mobil-oyun/design \
  -H "Authorization: Bearer $TOKEN"

# İndir
curl -O http://localhost:8080/api/projects/mobil-oyun/design/karakter.fbx \
  -H "Authorization: Bearer $TOKEN"

# Sil
curl -X DELETE http://localhost:8080/api/projects/mobil-oyun/design/karakter.fbx \
  -H "Authorization: Bearer $TOKEN"
```

İzin verilen uzantılar `internal/api/design_handlers.go` içindeki `allowedDesignExt` listesinden genişletilebilir.

## Proje yapısı

```
cmd/server/main.go            giriş noktası, yapılandırma, ilk admin
internal/store/                kullanıcı/proje veri modeli + JSON depolama
internal/auth/                 bearer-token oturum yönetimi, admin kontrolü
internal/gitserver/             bare repo oluşturma/silme, git-http-backend sarmalayıcı
internal/api/                  HTTP route'lar ve tüm handler'lar
```

## Notlar / genişletme fikirleri

- Şu an kimlik doğrulama basit `sha256(salt+şifre)` ile yapılıyor; gerçek üretimde `golang.org/x/crypto/bcrypt` eklemek isteyebilirsiniz (bu proje bilinçli olarak sıfır harici bağımlılıkla tutuldu).
- Web arayüzü (dosya tarayıcı, commit geçmişi görüntüleme vb.) yok — bu bir API/backend'dir. İsterseniz üstüne basit bir SPA eklenebilir.
- SSH tabanlı git erişimi (git@sunucu:proje.git) eklemek isterseniz `internal/gitserver` içine bir SSH sunucusu (örn. `golang.org/x/crypto/ssh`) eklenmesi gerekir.

//
// - Yazılımcılar: git clone/push/pull ile koda katkı sağlar.
// - Tasarımcılar: 3D model / çizim dosyalarını REST API üzerinden yükler.
// - Proje açma/silme/düzenleme sadece admin kullanıcıya özeldir.
//
// Ortam değişkenleri:
//
//	KP_DATA_DIR      Kullanıcı/proje meta verisinin tutulduğu klasör (varsayılan: ./data)
//	KP_REPOS_DIR     Bare git depolarının tutulduğu klasör (varsayılan: ./data/repos)
//	KP_DESIGN_DIR    Tasarım dosyalarının tutulduğu klasör (varsayılan: ./data/design)
//	KP_LISTEN_ADDR   Dinlenecek adres (varsayılan: :8080)
//	KP_ADMIN_USER    İlk kurulumda oluşturulacak admin kullanıcı adı (varsayılan: admin)
//	KP_ADMIN_PASS    İlk kurulumda oluşturulacak admin şifresi (zorunlu, admin daha önce yoksa)
package main

import (
	"errors"
	"log"
	"net/http"
	"os"

	"kodplatform/internal/api"
	"kodplatform/internal/auth"
	"kodplatform/internal/gitserver"
	"kodplatform/internal/store"
)

func env(key, def string) string {
	if v := os.Getenv(key); v != "" {
		return v
	}
	return def
}

func main() {
	dataDir := env("KP_DATA_DIR", "./data")
	reposDir := env("KP_REPOS_DIR", dataDir+"/repos")
	designDir := env("KP_DESIGN_DIR", dataDir+"/design")
	listenAddr := env("KP_LISTEN_ADDR", ":8080")

	st, err := store.New(dataDir)
	if err != nil {
		log.Fatalf("depolama başlatılamadı: %v", err)
	}

	if err := os.MkdirAll(designDir, 0755); err != nil {
		log.Fatalf("tasarım klasörü oluşturulamadı: %v", err)
	}

	git, err := gitserver.New(reposDir)
	if err != nil {
		log.Fatalf("git sunucusu başlatılamadı: %v", err)
	}

	ensureInitialAdmin(st)

	authMgr := auth.NewManager(st)
	a := api.New(st, authMgr, git, designDir)

	log.Printf("kodplatform %s adresinde dinliyor", listenAddr)
	log.Printf("veri klasörü: %s | git depoları: %s | tasarım dosyaları: %s", dataDir, reposDir, designDir)
	if err := http.ListenAndServe(listenAddr, a.Routes()); err != nil {
		log.Fatal(err)
	}
}

// ensureInitialAdmin, hiç admin kullanıcı yoksa KP_ADMIN_USER/KP_ADMIN_PASS
// ortam değişkenlerinden ilk admin hesabını oluşturur.
func ensureInitialAdmin(st *store.Store) {
	for _, u := range st.ListUsers() {
		if u.Role == store.RoleAdmin {
			return // zaten bir admin var
		}
	}
	username := env("KP_ADMIN_USER", "admin")
	password := os.Getenv("KP_ADMIN_PASS")
	if password == "" {
		log.Println("UYARI: Hiç admin kullanıcı yok ve KP_ADMIN_PASS tanımlı değil.")
		log.Println("İlk admini oluşturmak için KP_ADMIN_USER ve KP_ADMIN_PASS ile yeniden başlatın.")
		return
	}
	_, err := st.CreateUser(username, password, store.RoleAdmin)
	if err != nil && !errors.Is(err, store.ErrAlreadyExists) {
		log.Fatalf("ilk admin oluşturulamadı: %v", err)
	}
	log.Printf("ilk admin kullanıcı oluşturuldu: %s", username)
}

package api

import (
	"errors"
	"net/http"
	"regexp"

	"kodplatform/internal/store"
)

var slugRe = regexp.MustCompile(`^[a-z0-9]([a-z0-9-]{0,62}[a-z0-9])?$`)

// ---- Kullanıcı yönetimi ----

type createUserRequest struct {
	Username string `json:"username"`
	Password string `json:"password"`
	Role     string `json:"role"` // "developer" | "designer" | "admin"
}

func (a *API) handleAdminCreateUser(w http.ResponseWriter, r *http.Request) {
	var req createUserRequest
	if err := decodeJSON(r, &req); err != nil {
		writeError(w, http.StatusBadRequest, "geçersiz istek gövdesi")
		return
	}
	role := store.Role(req.Role)
	switch role {
	case store.RoleAdmin, store.RoleDeveloper, store.RoleDesigner:
	default:
		writeError(w, http.StatusBadRequest, "role şu değerlerden biri olmalı: admin, developer, designer")
		return
	}
	if req.Username == "" || len(req.Password) < 6 {
		writeError(w, http.StatusBadRequest, "kullanıcı adı zorunlu, şifre en az 6 karakter olmalı")
		return
	}
	u, err := a.st.CreateUser(req.Username, req.Password, role)
	if errors.Is(err, store.ErrAlreadyExists) {
		writeError(w, http.StatusConflict, "bu kullanıcı adı zaten kullanılıyor")
		return
	} else if err != nil {
		writeError(w, http.StatusInternalServerError, err.Error())
		return
	}
	writeJSON(w, http.StatusCreated, map[string]string{"username": u.Username, "role": string(u.Role)})
}

func (a *API) handleAdminListUsers(w http.ResponseWriter, r *http.Request) {
	users := a.st.ListUsers()
	out := make([]map[string]string, 0, len(users))
	for _, u := range users {
		out = append(out, map[string]string{"username": u.Username, "role": string(u.Role)})
	}
	writeJSON(w, http.StatusOK, out)
}

func (a *API) handleAdminDeleteUser(w http.ResponseWriter, r *http.Request) {
	username := r.PathValue("username")
	if err := a.st.DeleteUser(username); errors.Is(err, store.ErrNotFound) {
		writeError(w, http.StatusNotFound, "kullanıcı bulunamadı")
		return
	} else if err != nil {
		writeError(w, http.StatusInternalServerError, err.Error())
		return
	}
	w.WriteHeader(http.StatusNoContent)
}

type createProjectRequest struct {
	ID          string   `json:"id"`          // örn: "mobil-uygulama-x" (git deposu bu isimle oluşur)
	Name        string   `json:"name"`
	Description string   `json:"description"`
	Field       string   `json:"field"`
	Members     []string `json:"members"`
}

func (a *API) handleAdminCreateProject(w http.ResponseWriter, r *http.Request) {
	var req createProjectRequest
	if err := decodeJSON(r, &req); err != nil {
		writeError(w, http.StatusBadRequest, "geçersiz istek gövdesi")
		return
	}
	if !slugRe.MatchString(req.ID) {
		writeError(w, http.StatusBadRequest, "id sadece küçük harf, rakam ve '-' içerebilir (örn: mobil-uygulama-x)")
		return
	}
	// Üye olarak eklenen kullanıcıların gerçekten var olduğunu doğrula.
	for _, m := range req.Members {
		if _, ok := a.st.GetUser(m); !ok {
			writeError(w, http.StatusBadRequest, "tanımsız kullanıcı üye olarak eklenemez: "+m)
			return
		}
	}
	p, err := a.st.CreateProject(req.ID, req.Name, req.Description, req.Field, req.Members)
	if errors.Is(err, store.ErrAlreadyExists) {
		writeError(w, http.StatusConflict, "bu id ile bir proje zaten var")
		return
	} else if err != nil {
		writeError(w, http.StatusInternalServerError, err.Error())
		return
	}
	if err := a.git.CreateRepo(p.ID); err != nil {
		_ = a.st.DeleteProject(p.ID) // tutarlılık için geri al
		writeError(w, http.StatusInternalServerError, "git deposu oluşturulamadı: "+err.Error())
		return
	}
	if err := a.ensureDesignDir(p.ID); err != nil {
		writeError(w, http.StatusInternalServerError, "tasarım klasörü oluşturulamadı: "+err.Error())
		return
	}
	writeJSON(w, http.StatusCreated, p)
}

func (a *API) handleAdminDeleteProject(w http.ResponseWriter, r *http.Request) {
	id := r.PathValue("id")
	if err := a.st.DeleteProject(id); errors.Is(err, store.ErrNotFound) {
		writeError(w, http.StatusNotFound, "proje bulunamadı")
		return
	} else if err != nil {
		writeError(w, http.StatusInternalServerError, err.Error())
		return
	}
	if err := a.git.DeleteRepo(id); err != nil {
		writeError(w, http.StatusInternalServerError, "git deposu silinemedi: "+err.Error())
		return
	}
	if err := a.removeDesignDir(id); err != nil {
		writeError(w, http.StatusInternalServerError, "tasarım klasörü silinemedi: "+err.Error())
		return
	}
	w.WriteHeader(http.StatusNoContent)
}

	} else if err != nil {
		writeError(w, http.StatusInternalServerError, err.Error())
		return
	}
	writeJSON(w, http.StatusOK, p)
}

// Package api, HTTP yönlendirmelerini (routing) ve tüm handler'ları bir araya
// getiren ana katmandır.
package api

import (
	"net/http"

	"kodplatform/internal/auth"
	"kodplatform/internal/gitserver"
	"kodplatform/internal/store"
)

type API struct {
	st         *store.Store
	authMgr    *auth.Manager
	git        *gitserver.Server
	designRoot string
}

func New(st *store.Store, authMgr *auth.Manager, git *gitserver.Server, designRoot string) *API {
	return &API{st: st, authMgr: authMgr, git: git, designRoot: designRoot}
}

func (a *API) Routes() http.Handler {
	mux := http.NewServeMux()

	// --- Kimlik doğrulama ---
	mux.HandleFunc("POST /api/login", a.handleLogin)
	mux.Handle("POST /api/logout", a.authMgr.RequireUser(http.HandlerFunc(a.handleLogout)))
	mux.Handle("GET /api/me", a.authMgr.RequireUser(http.HandlerFunc(a.handleMe)))

	// --- Sadece admin: kullanıcı yönetimi ---
	mux.Handle("POST /api/admin/users", a.authMgr.RequireAdmin(http.HandlerFunc(a.handleAdminCreateUser)))
	mux.Handle("GET /api/admin/users", a.authMgr.RequireAdmin(http.HandlerFunc(a.handleAdminListUsers)))
	mux.Handle("DELETE /api/admin/users/{username}", a.authMgr.RequireAdmin(http.HandlerFunc(a.handleAdminDeleteUser)))

	// --- Sadece admin: proje açma/silme/düzenleme ---
	mux.Handle("POST /api/admin/projects", a.authMgr.RequireAdmin(http.HandlerFunc(a.handleAdminCreateProject)))
	mux.Handle("DELETE /api/admin/projects/{id}", a.authMgr.RequireAdmin(http.HandlerFunc(a.handleAdminDeleteProject)))
	mux.Handle("PATCH /api/admin/projects/{id}", a.authMgr.RequireAdmin(http.HandlerFunc(a.handleAdminUpdateProject)))

	// --- Giriş yapmış herkes (yetkisi olduğu projeler için) ---
	mux.Handle("GET /api/projects", a.authMgr.RequireUser(http.HandlerFunc(a.handleListProjects)))
	mux.Handle("GET /api/projects/{id}", a.authMgr.RequireUser(http.HandlerFunc(a.handleGetProject)))

	// --- Tasarım dosyaları (3D model, çizim vb.) ---
	mux.Handle("POST /api/projects/{id}/design", a.authMgr.RequireUser(http.HandlerFunc(a.handleUploadDesign)))
	mux.Handle("GET /api/projects/{id}/design", a.authMgr.RequireUser(http.HandlerFunc(a.handleListDesign)))
	mux.Handle("GET /api/projects/{id}/design/{filename}", a.authMgr.RequireUser(http.HandlerFunc(a.handleDownloadDesign)))
	mux.Handle("DELETE /api/projects/{id}/design/{filename}", a.authMgr.RequireUser(http.HandlerFunc(a.handleDeleteDesign)))

	// --- Git smart HTTP (clone/fetch/push) — kendi Basic Auth kontrolünü yapar ---
	mux.HandleFunc("/git/", a.handleGit)

	return mux
}
kodplatform/internal/api/auth_handlers.go
package api

import (
	"net/http"

	"kodplatform/internal/auth"
)

type loginRequest struct {
	Username string `json:"username"`
	Password string `json:"password"`
}

type loginResponse struct {
	Token    string `json:"token"`
	Username string `json:"username"`
	Role     string `json:"role"`
}

func (a *API) handleLogin(w http.ResponseWriter, r *http.Request) {
	var req loginRequest
	if err := decodeJSON(r, &req); err != nil {
		writeError(w, http.StatusBadRequest, "geçersiz istek gövdesi")
		return
	}
	tok, u, ok := a.authMgr.Login(req.Username, req.Password)
	if !ok {
		writeError(w, http.StatusUnauthorized, "kullanıcı adı veya şifre hatalı")
		return
	}
	writeJSON(w, http.StatusOK, loginResponse{Token: tok, Username: u.Username, Role: string(u.Role)})
}

func (a *API) handleLogout(w http.ResponseWriter, r *http.Request) {
	tok := r.Header.Get("Authorization")
	if len(tok) > 7 && tok[:7] == "Bearer " {
		tok = tok[7:]
	}
	a.authMgr.Logout(tok)
	w.WriteHeader(http.StatusNoContent)
}

func (a *API) handleMe(w http.ResponseWriter, r *http.Request) {
	u := auth.UserFromContext(r.Context())
	writeJSON(w, http.StatusOK, map[string]string{
		"username": u.Username,
		"role":     string(u.Role),
	})
}

// safeFilename, dizin gezinme (path traversal) saldırılarına karşı dosya adını temizler.
func safeFilename(name string) (string, error) {
	base := filepath.Base(name)
	if base == "." || base == "/" || base == "" || strings.Contains(name, "..") {
		return "", fmt.Errorf("geçersiz dosya adı")
	}
	return base, nil
}

func (a *API) handleUploadDesign(w http.ResponseWriter, r *http.Request) {
	projectID, ok := a.requireProjectAccess(w, r)
	if !ok {
		return
	}
	r.Body = http.MaxBytesReader(w, r.Body, maxUploadSize)
	if err := r.ParseMultipartForm(32 << 20); err != nil {
		writeError(w, http.StatusBadRequest, "form ayrıştırılamadı (dosya çok mu büyük?): "+err.Error())
		return
	}
	file, header, err := r.FormFile("file")
	if err != nil {
		writeError(w, http.StatusBadRequest, "'file' alanında bir dosya bekleniyor")
		return
	}
	defer file.Close()

	name, err := safeFilename(header.Filename)
	if err != nil {
		writeError(w, http.StatusBadRequest, err.Error())
		return
	}
	ext := strings.ToLower(filepath.Ext(name))
	if !allowedDesignExt[ext] {
		writeError(w, http.StatusBadRequest, "izin verilmeyen dosya türü: "+ext)
		return
	}

	dstPath := filepath.Join(a.designRoot, projectID, name)
	dst, err := os.Create(dstPath)
	if err != nil {
		writeError(w, http.StatusInternalServerError, "dosya kaydedilemedi: "+err.Error())
		return
	}
	defer dst.Close()
	if _, err := io.Copy(dst, file); err != nil {
		writeError(w, http.StatusInternalServerError, "dosya yazılamadı: "+err.Error())
		return
	}
	writeJSON(w, http.StatusCreated, map[string]string{"filename": name})
}

// handleGit, "git clone/fetch/push http://.../git/<proje-id>.git" isteklerini
// karşılar. Git istemcisi kimlik bilgilerini HTTP Basic Auth ile gönderir;
// burada doğrulanır ve kullanıcının bu projeye erişimi olup olmadığı kontrol
// edilir, ardından istek git-http-backend'e devredilir.
func (a *API) handleGit(w http.ResponseWriter, r *http.Request) {
	username, password, hasAuth := r.BasicAuth()
	if !hasAuth || !a.st.VerifyPassword(username, password) {
		w.Header().Set("WWW-Authenticate", `Basic realm="kodplatform git"`)
		writeError(w, http.StatusUnauthorized, "git kimlik doğrulaması başarısız")
		return
	}
	user, _ := a.st.GetUser(username)

	projectID := extractProjectID(r.URL.Path)
	if projectID == "" {
		writeError(w, http.StatusBadRequest, "geçersiz git yolu")
		return
	}
	p, ok := a.st.GetProject(projectID)
	if !ok {
		writeError(w, http.StatusNotFound, "proje bulunamadı")
		return
	}
	if user.Role != store.RoleAdmin && !p.HasMember(user.Username) {
		writeError(w, http.StatusForbidden, "bu projenin git deposuna erişim yetkiniz yok")
		return
	}

	a.git.Handler(username).ServeHTTP(w, r)
}

// extractProjectID "/git/<id>.git/..." yolundan proje id'sini çıkarır.
func extractProjectID(path string) string {
	path = strings.TrimPrefix(path, "/git/")
	idx := strings.Index(path, ".git")
	if idx < 0 {
		return ""
	}
	return path[:idx]
}

// Package auth, web API için basit bir bearer-token oturum mekanizması
// sağlar. Git işlemleri (clone/push/pull) için ise HTTP Basic Auth
// kullanılır (git istemcileri bunu doğal olarak destekler).
package auth

import (
	"crypto/rand"
	"encoding/hex"
	"net/http"
	"strings"
	"sync"
	"time"

	"kodplatform/internal/store"
)

type session struct {
	username string
	expires  time.Time
}

type Manager struct {
	mu       sync.Mutex
	sessions map[string]session
	st       *store.Store
	ttl      time.Duration
}

func NewManager(st *store.Store) *Manager {
	m := &Manager{
		sessions: map[string]session{},
		st:       st,
		ttl:      12 * time.Hour,
	}
	go m.cleanupLoop()
	return m
}

func (m *Manager) cleanupLoop() {
	for range time.Tick(time.Hour) {
		m.mu.Lock()
		now := time.Now()
		for tok, s := range m.sessions {
			if now.After(s.expires) {
				delete(m.sessions, tok)
			}
		}
		m.mu.Unlock()
	}
}

func newToken() (string, error) {
	b := make([]byte, 24)
	if _, err := rand.Read(b); err != nil {
		return "", err
	}
	return hex.EncodeToString(b), nil
}

// Login kullanıcı adı/şifreyi doğrular ve bir oturum token'ı döndürür.
func (m *Manager) Login(username, password string) (string, *store.User, bool) {
	if !m.st.VerifyPassword(username, password) {
		return "", nil, false
	}
	u, _ := m.st.GetUser(username)
	tok, err := newToken()
	if err != nil {
		return "", nil, false
	}
	m.mu.Lock()
	m.sessions[tok] = session{username: username, expires: time.Now().Add(m.ttl)}
	m.mu.Unlock()
	return tok, u, true
}

func (m *Manager) Logout(token string) {
	m.mu.Lock()
	delete(m.sessions, token)
	m.mu.Unlock()
}

// UserFromToken token'a karşılık gelen kullanıcıyı döndürür.
func (m *Manager) UserFromToken(token string) (*store.User, bool) {
	m.mu.Lock()
	s, ok := m.sessions[token]
	m.mu.Unlock()
	if !ok || time.Now().After(s.expires) {
		return nil, false
	}
	return m.st.GetUser(s.username)
}

func bearerToken(r *http.Request) string {
	h := r.Header.Get("Authorization")
	if strings.HasPrefix(h, "Bearer ") {
		return strings.TrimPrefix(h, "Bearer ")
	}
	// Kolaylık olsun diye X-Auth-Token header'ı da desteklenir.
	return r.Header.Get("X-Auth-Token")
}

// RequireUser, geçerli bir oturum token'ı arar ve context'e kullanıcıyı ekler.
type ctxKey string

const userCtxKey ctxKey = "user"

func (m *Manager) RequireUser(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		tok := bearerToken(r)
		if tok == "" {
			http.Error(w, "yetkisiz: token eksik", http.StatusUnauthorized)
			return
		}
		u, ok := m.UserFromToken(tok)
		if !ok {
			http.Error(w, "yetkisiz: geçersiz veya süresi dolmuş token", http.StatusUnauthorized)
			return
		}
		ctx := WithUser(r.Context(), u)
		next.ServeHTTP(w, r.WithContext(ctx))
	})
}

// RequireAdmin sadece admin rolündeki kullanıcıya izin verir.
func (m *Manager) RequireAdmin(next http.Handler) http.Handler {
	return m.RequireUser(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		u := UserFromContext(r.Context())
		if u == nil || u.Role != store.RoleAdmin {
			http.Error(w, "yasak: bu işlem sadece yönetici tarafından yapılabilir", http.StatusForbidden)
			return
		}
		next.ServeHTTP(w, r)
	}))
}

// Package gitserver, her proje için bir "bare" Git deposu oluşturur/siler
// ve Git'in kendi "git-http-backend" CGI programını kullanarak
// clone/fetch/push işlemlerini "smart HTTP" protokolü üzerinden sunar.
//
// Bu, Gitea/Gogs gibi projelerin de temelde kullandığı, kanıtlanmış bir
// yaklaşımdır: Go tarafında kimlik doğrulama + yetkilendirme yapılır,
// asıl git protokol mantığı ise git'in kendi güvenilir binary'sine
// devredilir.
package gitserver

import (
	"fmt"
	"net/http/cgi"
	"os"
	"os/exec"
	"path/filepath"
)

type Server struct {
	ReposRoot      string // örn: /var/lib/kodplatform/repos
	GitHTTPBackend string // örn: /usr/lib/git-core/git-http-backend
}

func New(reposRoot string) (*Server, error) {
	// git-http-backend, GIT_PROJECT_ROOT'u kendi çalışma dizinine göre değil
	// mutlak (absolute) olarak yorumlar; bu yüzden yolu burada mutlaklaştırıyoruz.
	abs, err := filepath.Abs(reposRoot)
	if err != nil {
		return nil, err
	}
	if err := os.MkdirAll(abs, 0755); err != nil {
		return nil, err
	}
	path, err := findGitHTTPBackend()
	if err != nil {
		return nil, err
	}
	return &Server{ReposRoot: abs, GitHTTPBackend: path}, nil
}

func findGitHTTPBackend() (string, error) {
	candidates := []string{
		"/usr/lib/git-core/git-http-backend",
		"/usr/libexec/git-core/git-http-backend",
	}
	for _, c := range candidates {
		if _, err := os.Stat(c); err == nil {
			return c, nil
		}
	}
	if p, err := exec.LookPath("git-http-backend"); err == nil {
		return p, nil
	}
	return "", fmt.Errorf("git-http-backend bulunamadı; 'git' paketinin kurulu olduğundan emin olun")
}

// repoDir, projenin bare deposunun disk yolunu döndürür: <reposRoot>/<id>.git
func (s *Server) repoDir(projectID string) string {
	return filepath.Join(s.ReposRoot, projectID+".git")
}

// CreateRepo verilen proje için boş bir bare depo oluşturur.
func (s *Server) CreateRepo(projectID string) error {
	dir := s.repoDir(projectID)
	if _, err := os.Stat(dir); err == nil {
		return fmt.Errorf("depo zaten var: %s", dir)
	}
	cmd := exec.Command("git", "init", "--bare", dir)
	if out, err := cmd.CombinedOutput(); err != nil {
		return fmt.Errorf("git init --bare başarısız: %v (%s)", err, string(out))
	}
	// Bu depoyu "export edilebilir" işaretle; aksi halde git-http-backend
	// GIT_HTTP_EXPORT_ALL olmadan reddeder.
	f, err := os.Create(filepath.Join(dir, "git-daemon-export-ok"))
	if err != nil {
		return err
	}
	return f.Close()
}

// DeleteRepo projenin bare deposunu diskten kaldırır.
func (s *Server) DeleteRepo(projectID string) error {
	dir := s.repoDir(projectID)
	if _, err := os.Stat(dir); os.IsNotExist(err) {
		return nil
	}
	return os.RemoveAll(dir)
}

// Handler, git-http-backend'i CGI olarak çalıştıran bir http.Handler döndürür.
// remoteUser: git-http-backend'e REMOTE_USER olarak geçirilecek, zaten kimliği
// doğrulanmış kullanıcı adı (commit yazarı/loglama amaçlı).
func (s *Server) Handler(remoteUser string) *cgi.Handler {
	return &cgi.Handler{
		Path: s.GitHTTPBackend,
		Root: "/git",
		Dir:  s.ReposRoot,
		Env: []string{
			"GIT_PROJECT_ROOT=" + s.ReposRoot,
			"GIT_HTTP_EXPORT_ALL=1",
			"REMOTE_USER=" + remoteUser,
		},
	}
}

kodplatform/internal/store/store.go
// Package store, kullanıcı ve proje verilerini basit JSON dosyalarında
// tutan, eşzamanlılığa (concurrency) karşı kilitli (mutex) bir depolama
// katmanı sağlar. Harici bir veritabanına ihtiyaç duymaz; küçük/orta
// ölçekli bir ekip içi platform için yeterlidir.
package store

import (
	"crypto/rand"
	"crypto/sha256"
	"encoding/hex"
	"encoding/json"
	"errors"
	"fmt"
	"os"
	"path/filepath"
	"sync"
	"time"
)

var (
	ErrNotFound      = errors.New("bulunamadı")
	ErrAlreadyExists = errors.New("zaten mevcut")
)

type Store struct {
	mu       sync.RWMutex
	dataDir  string
	users    map[string]*User
	projects map[string]*Project
}

func New(dataDir string) (*Store, error) {
	if err := os.MkdirAll(dataDir, 0755); err != nil {
		return nil, err
	}
	s := &Store{
		dataDir:  dataDir,
		users:    map[string]*User{},
		projects: map[string]*Project{},
	}
	if err := s.load(); err != nil {
		return nil, err
	}
	return s, nil
}

func (s *Store) usersPath() string    { return filepath.Join(s.dataDir, "users.json") }
func (s *Store) projectsPath() string { return filepath.Join(s.dataDir, "projects.json") }

func (s *Store) load() error {
	if b, err := os.ReadFile(s.usersPath()); err == nil {
		var list []*User
		if err := json.Unmarshal(b, &list); err != nil {
			return fmt.Errorf("users.json okunamadı: %w", err)
		}
		for _, u := range list {
			s.users[u.Username] = u
		}
	}
	if b, err := os.ReadFile(s.projectsPath()); err == nil {
		var list []*Project
		if err := json.Unmarshal(b, &list); err != nil {
			return fmt.Errorf("projects.json okunamadı: %w", err)
		}
		for _, p := range list {
			s.projects[p.ID] = p
		}
	}
	return nil
}

// saveUsersLocked ve saveProjectsLocked, mu zaten kilitliyken çağrılmalıdır.
func (s *Store) saveUsersLocked() error {
	list := make([]*User, 0, len(s.users))
	for _, u := range s.users {
		list = append(list, u)
	}
	return writeJSONAtomic(s.usersPath(), list)
}

func (s *Store) saveProjectsLocked() error {
	list := make([]*Project, 0, len(s.projects))
	for _, p := range s.projects {
		list = append(list, p)
	}
	return writeJSONAtomic(s.projectsPath(), list)
}

func writeJSONAtomic(path string, v interface{}) error {
	b, err := json.MarshalIndent(v, "", "  ")
	if err != nil {
		return err
	}
	tmp := path + ".tmp"
	if err := os.WriteFile(tmp, b, 0644); err != nil {
		return err
	}
	return os.Rename(tmp, path)
}

// ---- Şifre yardımcıları ----

func hashPassword(password, salt string) string {
	h := sha256.Sum256([]byte(salt + ":" + password))
	return hex.EncodeToString(h[:])
}

func newSalt() (string, error) {
	b := make([]byte, 16)
	if _, err := rand.Read(b); err != nil {
		return "", err
	}
	return hex.EncodeToString(b), nil
}

// ---- Kullanıcı işlemleri ----

func (s *Store) CreateUser(username, password string, role Role) (*User, error) {
	s.mu.Lock()
	defer s.mu.Unlock()
	if _, ok := s.users[username]; ok {
		return nil, ErrAlreadyExists
	}
	salt, err := newSalt()
	if err != nil {
		return nil, err
	}
	u := &User{
		Username:     username,
		Salt:         salt,
		PasswordHash: hashPassword(password, salt),
		Role:         role,
		CreatedAt:    time.Now(),
	}
	s.users[username] = u
	if err := s.saveUsersLocked(); err != nil {
		return nil, err
	}
	return u, nil
}

func (s *Store) DeleteUser(username string) error {
	s.mu.Lock()
	defer s.mu.Unlock()
	if _, ok := s.users[username]; !ok {
		return ErrNotFound
	}
	delete(s.users, username)
	return s.saveUsersLocked()
}

func (s *Store) GetUser(username string) (*User, bool) {
	s.mu.RLock()
	defer s.mu.RUnlock()
	u, ok := s.users[username]
	return u, ok
}

func (s *Store) ListUsers() []*User {
	s.mu.RLock()
	defer s.mu.RUnlock()
	list := make([]*User, 0, len(s.users))
	for _, u := range s.users {
		list = append(list, u)
	}
	return list
}

func (s *Store) VerifyPassword(username, password string) bool {
	s.mu.RLock()
	u, ok := s.users[username]
	s.mu.RUnlock()
	if !ok {
		return false
	}
	return hashPassword(password, u.Salt) == u.PasswordHash
}

// ---- Proje işlemleri (sadece admin tarafında çağrılacak şekilde API'de korunur) ----

func (s *Store) CreateProject(id, name, description, field string, members []string) (*Project, error) {
	s.mu.Lock()
	defer s.mu.Unlock()
	if _, ok := s.projects[id]; ok {
		return nil, ErrAlreadyExists
	}
	p := &Project{
		ID:          id,
		Name:        name,
		Description: description,
		Field:       field,
		Members:     members,
		CreatedAt:   time.Now(),
		UpdatedAt:   time.Now(),
	}
	s.projects[id] = p
	if err := s.saveProjectsLocked(); err != nil {
		return nil, err
	}
	return p, nil
}

func (s *Store) DeleteProject(id string) error {
	s.mu.Lock()
	defer s.mu.Unlock()
	if _, ok := s.projects[id]; !ok {
		return ErrNotFound
	}
	delete(s.projects, id)
	return s.saveProjectsLocked()
}

// UpdateProject verilen alanları günceller (boş string/nil geçilirse değişmez).
func (s *Store) UpdateProject(id string, name, description, field *string, members *[]string) (*Project, error) {
	s.mu.Lock()
	defer s.mu.Unlock()
	p, ok := s.projects[id]
	if !ok {
		return nil, ErrNotFound
	}
	if name != nil {
		p.Name = *name
	}
	if description != nil {
		p.Description = *description
	}
	if field != nil {
		p.Field = *field
	}
	if members != nil {
		p.Members = *members
	}
	p.UpdatedAt = time.Now()
	if err := s.saveProjectsLocked(); err != nil {
		return nil, err
	}
	return p, nil
}

func (s *Store) GetProject(id string) (*Project, bool) {
	s.mu.RLock()
	defer s.mu.RUnlock()
	p, ok := s.projects[id]
	return p, ok
}

func (s *Store) ListProjects() []*Project {
	s.mu.RLock()
	defer s.mu.RUnlock()
	list := make([]*Project, 0, len(s.projects))
	for _, p := range s.projects {
		list = append(list, p)
	}
	return list
}
