# Project Structure

Understanding how GoShare organizes projects and data on disk.

## Directory Layout

```
~/
├── GoShareProjects/          # All projects
│   ├── my-project/
│   │   ├── .goshare.json     # Project metadata
│   │   ├── index.html        # Generated project page
│   │   ├── src/              # Your source files
│   │   ├── docs/             # Your documentation
│   │   └── ...               # Any other files
│   └── another-project/
│       ├── .goshare.json
│       ├── index.html
│       └── ...
│
└── GoShareShares/            # Share archives (auto-cleanup after 7 days)
    ├── aB3x9K2m.zip          # Project archive
    ├── aB3x9K2m.json         # Share metadata
    ├── Xy7zP2qR.zip
    ├── Xy7zP2qR.json
    └── ...
```

## Project Directory (`~/GoShareProjects/<name>/`)

### `.goshare.json` - Project Metadata

```json
{
  "name": "my-project",
  "summary": "A sample Go project",
  "created_at": "2024-01-15T10:30:00Z",
  "updated_at": "2024-01-15T11:45:00Z",
  "path": "/home/user/GoShareProjects/my-project",
  "index_html": "/home/user/GoShareProjects/my-project/index.html"
}
```

| Field | Description |
|-------|-------------|
| `name` | Project name (directory name) |
| `summary` | User-provided description |
| `created_at` | ISO 8601 timestamp of creation |
| `updated_at` | ISO 8601 timestamp of last modification |
| `path` | Absolute path to project directory |
| `index_html` | Path to generated HTML page |

### `index.html` - Project Page

Auto-generated GitHub-style project page with:
- Project name and summary
- Creation/update timestamps
- File tree visualization
- Responsive design (mobile-friendly)
- No external dependencies (self-contained CSS)

**Customization:** Edit the template in `internal/project/manager.go` → `generateIndexHTML()`

### Your Files

Everything else in the project directory is your content:
- Source code
- Documentation
- Images
- Configuration files
- Build artifacts (if you copy them)

**Note:** Hidden files (starting with `.`) are excluded from the file tree display, except `.goshare.json`.

## Share Directory (`~/GoShareShares/`)

### Share Archive (`.zip`)

Contains the complete project directory structure **excluding** `.goshare.json`.

```
aB3x9K2m.zip
├── index.html
├── src/
│   ├── main.go
│   └── utils.go
├── docs/
│   └── README.md
└── go.mod
```

### Share Metadata (`.json`)

```json
{
  "code": "aB3x9K2m",
  "project_name": "my-project",
  "created_at": "2024-01-15T12:00:00Z",
  "expires_at": "2024-01-22T12:00:00Z",
  "zip_path": "/home/user/GoShareShares/aB3x9K2m.zip"
}
```

| Field | Description |
|-------|-------------|
| `code` | 8-character share code |
| `project_name` | Original project name |
| `created_at` | When share was created |
| `expires_at` | When share expires (7 days) |
| `zip_path` | Path to the ZIP archive |

---

## Share Code Format

- **Length:** 8 characters
- **Charset:** URL-safe base64 (A-Z, a-z, 0-9, -, _)
- **Generation:** Cryptographically random (6 bytes → base64)
- **Collision probability:** ~1 in 2.8 trillion

Example codes: `aB3x9K2m`, `Xy7zP2qR`, `h64bwBkf`

---

## Expiration & Cleanup

- **TTL:** 7 days from creation
- **Auto-cleanup:** Runs on `download` and `share` commands
- **Manual cleanup:** `goshare share-cleanup` (planned)

Expired shares are automatically removed:
1. `.json` metadata file deleted
2. `.zip` archive deleted

## File Tree Generation

The `index.html` file tree is generated by walking the project directory:

```
my-project/
├── .goshare.json          ← Hidden (excluded from tree)
├── index.html             ← Shown
├── src/
│   ├── main.go            ← Shown
│   └── utils.go           ← Shown
├── docs/
│   └── README.md          ← Shown
├── .git/                  ← Hidden (excluded)
└── build/                 ← Shown (if not hidden)
```

**Excluded from tree:**
- Files/directories starting with `.` (except `.goshare.json`)
- The `.goshare.json` file itself

## Permissions

| Path | Permissions | Owner |
|------|-------------|-------|
| `~/GoShareProjects/` | `0755` | User |
| `~/GoShareProjects/<project>/` | `0755` | User |
| `~/GoShareProjects/<project>/.goshare.json` | `0644` | User |
| `~/GoShareProjects/<project>/index.html` | `0644` | User |
| `~/GoShareShares/` | `0755` | User |
| `~/GoShareShares/*.zip` | `0644` | User |
| `~/GoShareShares/*.json` | `0644` | User |

## Backup & Migration

### Backup All Projects

```bash
# Backup projects
tar -czf goshare-projects-backup.tar.gz ~/GoShareProjects

# Backup shares (optional, they expire anyway)
tar -czf goshare-shares-backup.tar.gz ~/GoShareShares
```

### Restore

```bash
# Restore projects
tar -xzf goshare-projects-backup.tar.gz -C ~/

# Restore shares
tar -xzf goshare-shares-backup.tar.gz -C ~/
```

### Migrate to New Machine

1. Copy `~/GoShareProjects/` to new machine
2. Run `goshare list` to verify
3. Shares don't need migration (regenerate with `goshare share`)

## Disk Usage

Typical sizes:
- Empty project: ~2 KB (metadata + index.html)
- Project with 100 Go files: ~500 KB - 2 MB
- Share archive: Similar to project size (compressed)

```bash
# Check project sizes
du -sh ~/GoShareProjects/*

# Check share sizes
du -sh ~/GoShareShares/*
```

## Security Considerations

1. **No encryption** - Shares are plain ZIP files
2. **No authentication** - Anyone with code can download
3. **Local only** - Data never leaves your machine unless you share it
4. **Path traversal protection** - ZIP extraction validates paths
5. **No network access** - Except `public` command (Cloudflare tunnel)

**Best practices:**
- Share codes via secure channels (encrypted chat, password manager)
- Delete shares after use: `rm ~/GoShareShares/<code>*`
- Don't put secrets in shared projects
